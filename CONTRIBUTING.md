# Contributing

Issues and pull requests are welcome.

1. Open an issue describing the proposed change.
2. Create a branch from main.
3. Add or update tests for behavioral changes.
4. Run devtools::document() and devtools::check().
5. Submit a pull request with a short description of the change.

Do not commit identifiable CGM records, participant identifiers, access tokens,
or local file paths. Use simulated or fully de-identified example data.
